## 1. Suicide and Depression Detection

Classify text data, predicting whether it indicates suicidal ideation.

- **Dataset:** [SuicideWatch on Reddit](https://www.kaggle.com/datasets/nikhileswarkomati/suicide-watch) - A collection of posts from the "SuicideWatch" and "depression" subreddits.
- **Notebook:** [View on Kaggle](https://www.kaggle.com/code/i0nlyaziz/suicide-and-depression-text-classification)
- **Models & Techniques:**
  - Naive Bayes
  - Logistic Regression
  - LightGBM

## 2. Hate Speech Detection

Compares different NLP methodologies for classifying hateful speech in text.

- **Dataset:** [Hate Speech Detection - Curated Dataset](https://www.kaggle.com/datasets/waalbannyantudre/hate-speech-detection-curated-dataset/data)
- **Notebook:** [View on Kaggle](https://www.kaggle.com/code/abramova/hate-speech-detection-from-tf-idf-to-transformers)
- **Models & Techniques:**
  - **TF-IDF** with a Linear Regression model
  - **BERT** implemented with native PyTorch
  - Fine-tuning a transformer model using the **Hugging Face Trainer API**
